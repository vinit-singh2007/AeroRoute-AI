3. Soft Computing Engine — Dil of the System

AeroRoute ka core intelligence soft_computing.py module mein rehta hai. Yahan teen AI algorithms mil ke drone delivery ko safe, efficient aur intelligent banate hain: Genetic Algorithm (route optimization), A* Pathfinding (NFZ avoidance), aur Fuzzy Logic (real-time safety scoring).

🧬 Genetic Algorithm (GA)

Multi-waypoint delivery route ko evolutionary approach se optimize karta hai. Population-based search mein best routes "evolve" hoti hain generations ke through.

  • Population Size: 80 individuals
  • Generations: 120 iterations
  • Crossover Rate: 0.85 (85%)
  • Mutation Rate: 0.18 (18%)
  • Elite Count: 4 (preserved best)
  • Fitness = Distance + NFZ Penalty + Battery Penalty
  • Single-point crossover on waypoint segments
  • Mutation: Shift / Add / Remove intermediate waypoints
🔍 A* (A-Star) Pathfinding

Exact shortest collision-free path nikalta hai Mumbai Red Zones aur weather obstacles avoid karte hue. Dispatch mission mein ye hi primary algorithm use hoti hai.

  • Grid Resolution: ~350m per cell (0.0035°)
  • Connectivity: 8-directional moves
  • Max Iterations: 8,000 nodes
  • Safety Margin: +0.4 km around NFZ radius
  • Proximity Penalty: Graduated cost near NFZ borders
  • Weather Factor: 1.0x (calm) → 1.35x (extreme wind)
  • Heuristic: Haversine great-circle distance to goal
  • Direct Line Check: LoS test → bypass if NFZ-free

4. Fuzzy Flight Safety Index (FSI)

Har drone ka real-time Flight Safety Index (FSI 0–100) ek Mamdani-style Fuzzy Inference System se calculate hota hai. Teen inputs ke fuzzy membership functions define hain (triangular + trapezoidal), 18 IF-THEN rules apply hote hain, aur centroid defuzzification se final FSI score milta hai.

Input VariableRangeFuzzy SetsMF Type
Wind Gust0–30 m/sLow · Moderate · High · ExtremeTrapezoidal + Triangular
Battery Level0–100 %Critical · Low · Adequate · FullTrapezoidal + Triangular
Distance to Hub0–20 kmNear · Mid · FarTrapezoidal + Triangular
Output: FSI Score0–100Danger (15) · Caution (40) · Safe (70) · Optimal (90)Singleton Centroid
FSI Thresholds: FSI ≥ 65 → SAFE (Green) · FSI 35–64 → CAUTION (Yellow) · FSI < 35 → EMERGENCY RTB (Red, auto Return-to-Base command)
5. Battery Drain ML Model (Gradient Boosting)

ml_models.py mein ek scikit-learn Gradient Boosting Regressor trained hai jo har mission ke liye battery drain % predict karta hai. 1,500 synthetic training samples use hote hain realistic drone physics ke saath.

📊 Model Features (Inputs)
  • Payload Weight (0.1–5.0 kg)
  • Elevation Change (−200 to +500 m)
  • Flight Distance (0.5–25 km)
  • Wind Speed (0–18 m/s)
⚙️ Model Configuration
  • Estimators: 60 trees
  • Learning Rate: 0.10
  • Max Depth: 4
  • Subsample: 0.85
  • Output: Drain%, Remaining%, Risk Level, ±CI
  • Persistence: battery_model.pkl (cached on disk)

7. Database Layer — MongoDB + Motor

database.py mein async MongoDB client (Motor) ke through 4 collections manage hoti hain. Connection failure pe gracefully in-memory fallback hota hai — koi crash nahi.

🗄️ Collections
  • drones — Fleet registry, status, battery, GPS coords
  • missions — Order IDs, routes, ETA, payload, status
  • routes — GA/A* computed route logs with waypoints
  • telemetry_logs — Historical flight snapshots
🔗 Key DB Features
  • Connection: localhost:27017 ya env variable
  • Unique Index: drone.id, mission.order_id
  • Timeout: 3000ms serverSelection + connect
  • Fallback: In-memory dict if MongoDB unavailable
  • Upsert Pattern: Drone state sync on every update
  • Limit: Last 50 missions per query
8. LLM Pre-Flight Safety Advisor (Google Gemini)

llm_advisor.py — Mission dispatch se pehle ek AI advisor automatically analysis karta hai: payload weight, battery drain, wind conditions aur distance ki values Gemini (ya Groq LLaMA) ko bhejta hai aur structured JSON verdict milta hai.

Supported LLMs: Primary — Google Gemini 3.8 Flash (via GEMINI_API_KEY env var). Fallback — Groq Cloud LLaMA 3.3 70B (via GROQ_API_KEY). Agar dono unavailable hain toh deterministic offline rule-engine automatically activate hoti hai — koi silent failure nahi.
🤖 Verdict Types
  • CLEARED — Safe to dispatch
  • CAUTION — Proceed with monitoring
  • BLOCKED — Launch banned (overweight/low battery)
  • UNSAFE — Emergency conditions detected
📋 Analysis Inputs
  • Payload vs Max Payload Kg comparison
  • Current Battery % vs Predicted Drain %
  • Remaining battery after flight estimate
  • Wind gust conditions (m/s)
  • Flight distance (km) & Risk Score 0-100
DroneSimulator: Backend mein ek built-in real-time simulator bhi hai jo actual drones ki GPS movement, battery depletion, wind gust events, RTB triggers, aur parachute deployment simulate karta hai — WS telemetry stream ke through 1 Hz pe broadcast hoti hai.

11. Deployment & Running Locally
⚙️ Backend (FastAPI)
  • Port: 8000 (Uvicorn)
  • Command: uvicorn main:app --reload --port 8000
  • Env: .env — MONGODB_URL, GEMINI_API_KEY, GROQ_API_KEY
  • Auto-startup: ML model train + MongoDB connect + telemetry loop
🌐 Frontend (Vite + React)
  • Port: 5173 (Vite Dev Server)
  • Command: npm run dev
  • Proxy: /api → 8000, /ws → 8000 (WS)
  • Env: VITE_GOOGLE_MAPS_API_KEY, VITE_CESIUM_ION_TOKEN
  • Build: npm run build → dist/ folder
